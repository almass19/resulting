# RESULTING — кинематографичный сайт

Одностраничный сайт маркетингового агентства RESULTING (Казахстан, с 2020 года).
Чистый чёрный × костяной белый, золото ровно три раза, Unbounded × Cormorant Garamond,
скролл-скраб видео в hero, кинетический манифест, счётчики и hover-видео кейсов.

Статика без сборки: HTML + CSS + vanilla JS.

## Запуск

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Видео

Три клипа сгенерированы Seedance 2.0 (Higgsfield): std · 1080p · 16:9 · без звука · ~8 сек.

1. `assets/video/hero.mp4` — частицы-клики стекаются и воспламеняются в поток жидкого золота
   (перекодирован с GOP=4 для плавного скролл-скраба).
2. `assets/video/work.mp4` — боковой трекинг вдоль галереи светящихся дашбордов
   (сетка кейсов показывает четыре разных CSS-кропа этого клипа).
3. `assets/video/team.mp4` — силуэты команды в ночной студии, боке города за окном.

Файлы кладёт в репозиторий workflow `.github/workflows/fetch-assets.yml`
(запускается вручную: скачивает исходники с CDN, пережимает ffmpeg и коммитит).
